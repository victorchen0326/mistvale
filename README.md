# 霧谷傳說 Mistvale

瀏覽器可玩的黑暗奇幻角色扮演遊戲，介面為繁體中文。

在迷霧籠罩的山谷中建立冒險者、接下村莊公佈欄任務、探索四個區域、馴服魔物，並在祭壇面對最終之敵。

## 這份倉庫是什麼

這是《霧谷傳說》的**原始碼**。

- 原始碼網址：https://github.com/victorchen0326/mistvale
- 可直接遊玩、可分享給朋友的網址，請在 Grok Build 專案裡點 **Publish（發布）**。發布後會得到 `*.grok.me` 的 HTTPS 網址。

GitHub 本身只保存程式，不會自動變成可玩的網站。

## 遊戲特色

- 三種職業：戰士、法師、遊俀，各有獨立技能樹
- 回合制戰鬥，含攻擊軌跡與技能特效
- 區域獵獸：探索累積線索、發現巢穴、擊敗巢穴首領才能取得關鍵結晶
- 角色與區域魔物會隨等級成長；最終頭目固定 50 級
- 秘銀之後解鎖職業傳說武器（需三顆結晶與清輝靈枝）
- 隨時存檔／讀檔，標題畫面可「繼續冒險」

## 如何開始

1. 標題畫面選 **新的冒險**，建立角色
2. 在迷霧村莊找長者、看公佈欄接任務
3. 用地圖前往迷霧森林、礦洞、荒廢神殿與終焉祭壇
4. 探索累積線索後潛入巢穴；回村莊休息、商店、回報任務
5. 等級 40 且發現最終巢穴後，鍛造傳說武器，挑戰霧谷之龍

存檔存在瀏覽器本機，換裝置不會自動帶過去。

## 本機執行（開發者）

```bash
npm install
npm run dev
```

瀏覽器開啟開發伺服器後即可遊玩。
